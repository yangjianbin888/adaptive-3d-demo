# 自适应3D渲染 Demo

> **一个C语言最小实现：演示程序如何在"卡顿→死机"前自动感知、自我重构到60帧最优临界点。**

---

## 核心思想

多边形数量每秒自动 +1%，程序通过实时检测帧数（FPS），在跌破阈值时自动削减多边形数量，恢复到60帧流畅状态。

**不预设"最多多少多边形"，程序自己找到性能临界点。**

---

## 同构映射

| 3D渲染 | 知识库 |
|--------|--------|
| 多边形无脑 +1% | 资料无脑往里塞 |
| 帧数跌破60 → 自动削减 | 信息过载 → AI答得乱 |
| 程序自己找到临界点 | 只放"思维框架"，AI按你的思路干活 |
| 永远不会死机 | 永远不会"信息爆炸" |

**核心：不靠"越多越好"，而是找到"刚好够用"的最优临界点。**

---

## 编译与运行

```bash
gcc adaptive_3d_demo.c -o demo -lm
./demo
```

无需任何第三方库（默认使用终端模拟模式）。

### 可选：OpenGL 真实渲染

如需真实GPU渲染，编辑代码将 `#define USE_OPENGL 0` 改为 `1`，然后：

```bash
# Ubuntu/Debian
sudo apt-get install freeglut3-dev
# macOS
brew install freeglut

gcc adaptive_3d_demo.c -o demo -lGL -lglut -lm
./demo
```

## 自适应调整规则

```c
if (fps < 20.0f) {
    // 极度卡顿 → 紧急砍半（防死机）
    polygonCount *= 0.5f;
}
else if (fps < 55.0f) {
    // 开始卡顿 → 削减 10%（自我保护）
    polygonCount *= 0.9f;
}
else if (fps >= 60.0f) {
    // 流畅 → 试探 +2%（寻找上限）
    polygonCount *= 1.02f;
}
```
